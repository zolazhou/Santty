Link character-policy adaptations reference SwiftTerm 28c6d1d95de156a36a2eaa278177ee7f8a15d322,
Sources/SwiftTerm/Mac/UntrustedTerminalLink.swift, originally adapted from Ghostty:

Changes: use Santty's shared URL parser; reject encoded controls, credentials,
local files and custom handlers without probing the local filesystem.

Scheme URL tokens and cell-range mapping also reference SwiftTerm Terminal.swift
(ghosttyImplicitLinkRegex / implicitLinkMatch) at the same pinned revision;
modifier/hover lifecycle references MacTerminalView.swift. Changes: only the
scheme-URL branch, bounded owned VT soft-wrap groups, UTF-16-to-cell mapping,
no path heuristics or filesystem access, no truncated-prefix activation, and
