Native theme catalog adaptation

The 485 exact-name color records are extracted offline from libghostty-spm
1d84cf66fe29abd1f24f10b88dcfc25882cf68ee, Sources/GhosttyTheme (ThemeDefinition,
ThemeCatalog_Generated and Themes_*.swift). generate-theme-catalog.py validates
all initializer fields/catalog membership and records source SHA-256 values.
TerminalThemes.json is an internal frozen data artifact, not a user config format.
The runtime does not import GhosttyTheme/GhosttyTerminal or load the old C core.
No full Ghostty configuration/theme-file parser is provided. Colors, palette,
cursor text and selection data keep their original names/values; native typed
settings and publication/lifecycle glue are Santty adaptations.

CG/Metal renderer interfaces remain SwiftTerm's pinned MIT components; native
settings reuse their font/color/caret/opacity APIs without a second emulator.
Metadata is an owned bounded snapshot of the precompiled VT's title/pwd, never
filesystem-resolved. Core semantics and reset callback differences are probed
independently. Snapshot/host integration is not whole-app or GUI certification.
