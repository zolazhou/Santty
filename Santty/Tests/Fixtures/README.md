# Herdr workspace fixture

`herdr-workspace-v0.1.14.json` is synthetic data generated by Santty's stable
UUID projection, not a copy of a user's workspace.

Wire contract checked against `herdrdev/herdr-app` tag `v0.1.14`, commit
`2405bf388c568c3ed479f05b8e405ccfa44b3f2c`:

- `src/mirror.rs`: `Document`, `SharedSpace`, `SharedTab`, `capture`, `replace`.
- `src/layout.rs`: `Node`, `Kind`, `Content`, `Size`.
- `src/mirror_sync.rs`: `doc.get` / revision-checked `doc.set`.

The fixture was parsed by the **unmodified upstream Rust modules**
(`layout.rs`, `model.rs`, `mirror.rs`) in a temporary standalone serde executable.
`Document -> Model -> Document` round-tripped to the same JSON value, with one
space, one tab and terminal addresses `t1`, `t2`. This validates the desktop
schema, not a phone runtime or pixel-level layout compatibility.

Run `Scripts/check-herdr-workspace-schema.sh` to repeat the upstream check
(requires git, Cargo and network access; the reviewed source revision is checked
before compiling). It uses only a temporary directory and never connects to a core.

`HerdrWorkspaceDocumentTests.testExportMatchesUpstreamParserFixture` locks in the
Swift export against this fixture. The other codec tests cover opaque future
nodes, unknown fields and UInt64 metadata without making those nodes editable.
